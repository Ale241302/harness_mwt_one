Additional third-party skills in this directory
===============================================

Alongside the ECC catalog recorded in ECC-LICENSE.txt, this directory vendors
skills from four external repositories, all under the MIT License:

  - `landing-page-design/` — from elayadesign/ai-design-skills
    (https://github.com/elayadesign/ai-design-skills). Copied verbatim;
    model-invocable.
  - `scroll-world/` — from oso95/scroll-world
    (https://github.com/oso95/scroll-world). Copied with one change:
    `disable-model-invocation: true` was added so the heavy asset-generation
    skill stays user-invocable via `/scroll-world` and out of the model catalog.
  - `antislop/`, `antislop-ui/`, `antislop-copywriting/`, `antislop-human/`,
    `antislop-layoutmobile/`, `antislop-code/` — from miqdadbadjuber/anti-slop
    (https://github.com/miqdadbadjuber/anti-slop). Copied verbatim;
    model-invocable.
  - `find-skills/` — from vercel-labs/skills
    (https://github.com/vercel-labs/skills). Copied with one change:
    `disable-model-invocation: true` was added so the discovery helper stays
    user-invocable via `/find-skills` and out of the model catalog.

The model-invocation policy (the curated set versus `disable-model-invocation:
true`) is the only adaptation applied to the vendored skills.
