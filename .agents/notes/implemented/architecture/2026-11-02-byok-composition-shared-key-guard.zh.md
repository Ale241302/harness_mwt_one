# Agent Note: 自有密钥的组合、故障关闭的范围守卫与真实用量限制

Status: implemented

[English](2026-11-02-byok-composition-shared-key-guard.md) | 中文

## Problem

Mesa 收尾后仍有三处缺口，使 BYOK 承诺不成立。会话组合只看角色，因此 `client_b2b` 会话即使路由使用的是账户自己的密钥，仍保留共享密钥的提示词与产品工具掩码。守卫仍信任消息中的业务词和历史中的任意工具结果，分类器回退默认放行。产品文案还承诺自有密钥会取消一切限制，而网关代理、MCP 接口与供应商各自仍有上限。

## Decision

限制跟随请求实际使用的凭据。自有密钥要求请求显式携带 `credentialRef`，由可写存储（`file`）解析，且其值的 SHA-256 不在部署指纹集合中。没有引用即为共享，因为桌面代理路由用 `CONSOLA_TOKEN` 认证，路由未使用的已存密钥不能证明谁付费。`faberloom:usage-policy` 区块和产品工具掩码读取该状态；换钥在下一个请求生效，解除或恢复掩码，而 Space 隔离在两种密钥下都保持。

守卫对每个人类回合分类。词表快速通道和工具结果续接已删除；只有紧邻的上一回合被分类为 `work` 时的简短续接才放行，且凭据存储变化时该记忆被清除。`scopeFallback` 默认 `refuse`，无法核验的回合收到自己的文案，而不是“个人请求”的拒绝。

产品只陈述实际存在的限制。自有密钥的文案说明账户离开 FaberLoom 的范围限制，供应商仍施加其余额、配额与上下文窗口。`LLM_RATE_LIMIT_PER_MIN` 被导出并由 `/healthz` 与登录、MCP 窗口并列报告，MCP 429 指明其上限，文案门禁在“无限制”说法回归时失败。不发明 token 配额：部署无法计量它不调用的供应商。

## Consequences

- 会话可在回合之间改变行为而无需重建 fiber：提示词区块是 getter，掩码是按 agent 持有的 disposer。
- 守卫每个人类回合多一次小型分类调用。这是移除确定性绕过所付的代价。
- 路由未使用的已存密钥不再解锁个人用途，关闭了旧 `sharedCredentialRefs[0]` 回退造成的误判。
- Space 隔离现在在两种密钥下都对产品工具执行，与产品集合在同一个门禁里。
- 供应商余额、供应商速率限制、模型上下文窗口、MCP 120/分钟、登录 12/分钟与代理 120/分钟仍然存在。自有密钥只解除范围策略。
- `gateway/llm-proxy.test.mjs` 负责代理窗口：120 通过、121 为 429、窗口按账户独立、窗口会重新打开。

## Alternatives considered

**保留词表快速通道并增加更多词**被否决：任何固定词表在构造上就是绕过面，审计用一条含 “MWT” 的个人请求复现了它。

**把任意工具结果当作续接**被否决：它让个人请求搭上不相干的早期回合。续接现在需要已记录的工作判定与人类回合计数。

**请求没有引用时解析 `sharedCredentialRefs[0]`**被否决为误判：在代理路由上它把会话标记为自有，而付费的是部署。

**每次换钥都重建 agent fiber**被否决：它会与进行中的流失衡并重复注册提示词区块。动态区块加掩码 disposer 在回合边界达到同样效果。

**增加客户端月度 token 配额**被否决：那只是建议而非执行，部署永远看不到 BYOK 用量。

## Testing

`packages/faberloom/session-agent/tests/session-agent.spec.ts` 覆盖 `C-B01.1` 至 `C-B01.5` 与 `C-B02.1` 至 `C-B02.9`，包括已存密钥误判、安装时自有密钥组合、会话中换钥、凭据事件与回合边界的掩码移动、业务词绕过、工具历史绕过、无法核验的拒绝与缓存续接。`tests/copy-limits.spec.ts` 是 `C-B03.1`；`gateway/llm-proxy.test.mjs` 覆盖 `C-B03.2` 至 `C-B03.4`；`routing-e2e.host.spec.ts` 覆盖 `C-B03.6`；`gateway/gateway-limits.test.mjs` 覆盖 `C-B03.5` 与 `C-B03.7`。包测试 85 项；网关 7 项；包级 `tsc` 零错误。

## Deferred

供应商自身的余额与配额无法从产品端提高，且使用自有密钥时部署无法在供应商切断账户前告警。`C-B03.7` 固定 MCP 错误体并以源码断言其 429 状态行，因为网关离开部署环境无法启动；部署后的 `/healthz` 只有在本变更上线后才报告第三个窗口。四十字符以内、以续接词开头的个人短语（`dale, escribime un poema`）在分类器判定为工作的上一轮之后会免于分类；长度限制使它无法覆盖更长的请求。通过 `apiKeyEnv` 解析密钥的路由会经 `listProviders()` 报告该引用，因此路由胜出的存储值无需请求引用也算作账户自己的。分类器把个人请求答为 `work` 仍是模型错误，而不是确定性绕过。
