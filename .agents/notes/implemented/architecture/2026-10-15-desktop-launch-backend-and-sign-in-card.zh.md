# Agent Note: Desktop 启动本机 harness，登录界面与 Web 一致

Status: implemented

[English](2026-10-15-desktop-launch-backend-and-sign-in-card.md) | 中文

## Problem

Desktop 之前向操作者提供后端选择器：登录界面上的一组按钮、应用菜单中的 **Backend** 组，以及支撑它们的 `desktop-backend.json` 记录。因此同一次安装既可能运行本机 harness，也可能运行共享网关；该决策已归档为 `2026-10-14-desktop-backend-choice`。由此产生两个问题。

选择器要求操作者回答一个产品其实已经回答过的实现问题，并让应用失去唯一身份：同一个构建要么是这台电脑文件夹的编辑器，要么是服务器的客户端，两套数据互不相通，也无法从一侧读到另一侧。用同一个控制台账号在本机模式登录后，Agents 面板是空的：本机 harness 播种自己的 Agents 并读取自己的 Harness home，而 web 的行仍留在服务器上。

登录界面也已经和它所登录的页面脱节。它的文案把同一段话显示了两遍，带有已部署页面并不存在的后端分组，并且缺少已部署 `login` 页面的密码显示控件与找回链接。

## Decision

**Desktop 启动本机 harness；只有启动环境才能把安装指向网关。** `apps/desktop/src/launch-backend.ts` 解析 `DSH_DESKTOP_GATEWAY_URL`：给出源表示网关，空值与未设置都表示本机 harness。`apps/desktop/src/gateway.ts` 保存环境变量名与出厂 `DEFAULT_GATEWAY_URL`。Harness home 中没有任何记录保存后端，因此操作者在应用内的操作不会改变实际启动的后端，需要网关的部署仍然可以从启动器得到它。

**登录界面就是已部署页面的卡片。** 底色上的一张卡片：双色字标、控制台提示、每个字段一个标签、带显示控件的凭据字段、强调色提交按钮与找回链接；壳自有的语言组与外观开关保持原位。未登录界面此前重复渲染的那段文案已删除，卡片的提示成为该界面唯一的文案。

**找回密码留在应用内。** 该链接打开一个对话框，把输入的邮箱提交到 `{CONSOLA_API_BASE}/users/forgot-password/`，即已部署页面本来就调用的控制台接口，并原地显示控制台的中性答复。传输失败只以一条由语言字典拥有的消息呈现给操作者，而不是控制台自身的错误文本。

**共享界面在浏览器中打开。** 应用菜单新增的条目在默认浏览器中打开部署，web 的 Space、会话与产品模块都在那里。窗口本身绝不会切换到该界面：切换会停止正在运行的后端并重建窗口，而本机 harness 依旧是拥有这台电脑文件夹的那次安装。

## Alternatives considered

**保留选择器，只把它默认成本机 harness。** 操作者仍要回答一个界面无法说明其后果的问题，菜单也仍会提供一个“本机文件夹不可达”的状态。

**只保留网关模式。** 此时窗口就是 web 客户端，每个产品模块都能直接显示 web 的行，也无需构建任何传输机制。但这放弃了本机 harness 存在的理由：Workspace 是这台电脑上的文件夹。操作者要的是本机应用，所以本机应用保留。

**在本次改动里把 web 的产品行镜像到本机 harness。** 这是对“面板为空”的根本回答，而它是一项独立工程：两台主机之间的传输、每种资源的合并规则，以及行存储覆盖不到的技能与会话文件。把它塞进本次改动，会让登录界面在传输完成之前长期处于半迁移状态，因此推迟到它自己的 Agent Note。

**让登录界面与页面完全一致，不带壳自有的控件。** 已部署页面没有语言组，也没有外观开关，但壳需要为自己的界面保留二者，并且在 Host 启动之前就必须可用。

**把找回密码做成指向已部署页面的链接。** 这会为了一项壳本身就能用同一控制台地址提交的字段把操作者带出应用，而且在安装运行本机模式时，还要求部署能作为 web 源被访问。

## Consequences

应用有了唯一身份：它读取自己所在电脑上的文件夹，而 web 的共享界面在浏览器里只差一次菜单点击。`desktop-backend.json` 不再被读写，因此曾记录 `gateway` 的安装会在环境另有指示之前启动本机 harness。

登录卡片现在复制了已部署页面的设计，因此改动该页面就是改动两处；壳保留页面所没有的两个控件。找回密码要求控制台可达，而登录本来就有这一要求。

主按钮的米色文字配品牌强调色，即 `#F4F1ED` 配 `#C96442`，对比度为 3.46:1，未达到该字号 4.5:1 的门槛；本次改动把这套组合带进壳，而不是再引入第三种变体。[主按钮对比度 Agent Note](../bug-fix/2026-10-15-primary-button-contrast.zh.md) 以专用的主按钮表面色取代该组合，覆盖壳、网关登录页与 `packages/client/ui-theme`。

## Testing

`apps/desktop/tests/startup-renderer.spec.ts` 覆盖该卡片及其唯一的提示文案、密码显示、找回对话框的邮箱缺失、发送成功与被拒的两种结果、语言切换，以及未变动的加载与恢复界面。`apps/desktop/tests/main-startup.spec.ts` 覆盖本机启动与由环境指定、加载进 `persist:gateway` 的网关。`apps/desktop/tests/preload-app.spec.ts` 覆盖找回通道。oxlint、`verify-client-ui-i18n`、桌面端 TypeScript 面与 `verify-archived-agent-notes` 均通过。
